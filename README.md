### 🛠️ Setup Instructions

To make this work:
1. Replace `YOUR_GITHUB_USERNAME` and `YOUR_REPO_NAME` in this `README.md` file with your own GitHub username and repository name.
2. Push all files to your GitHub repository.
3. In your GitHub repository settings, go to **Settings** > **Actions** > **General**.
4. Scroll down to **Workflow permissions**, select **Read and write permissions**, and click **Save**.
5. Go to the **Actions** tab in your repository, select **Generate Snake Animation**, and click **Run workflow** to manually trigger the first build.
6. Once completed, a new branch named `output` will be created with the SVGs, and they will load perfectly on this page!
